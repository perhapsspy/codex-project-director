# 결정 기록

**2026-07-27**

- **배경:** 디렉터가 제품 결과를 충분히 소유하지 못한 채 작은 문제를 세션과 내부 에이전트로 계속 나누고, 각 의견과 국소 실패에 반응하면서 실제 완료로 수렴하지 못했다.
- **결정:** 제품 해석, 충분히 큰 세션 책임, 의견의 중요도 분류와 내부 에이전트 연쇄를 통한 간접 구현 인수 금지를 스킬의 중심 규칙으로 보강한다.
- **이유:** 감시자나 상세 장부는 증상을 관리하지만, 여러 전문 결과를 선별·통합해 큰 결과를 완료하는 디렉터의 본래 책임을 회복하지 못한다.
- **영향:** 기존 증거·복구 규칙은 보조 안전장치로 유지하며 고정 횟수와 프로젝트별 상태 형식은 일반 스킬 계약에 추가하지 않는다.

**2026-07-27**

- **배경:** 현재 디렉터 상태 문서는 즉시 행동과 대기를 보존하지만, 프로젝트별 제품 해석과 오래 유지할 판정 규칙을 소유하지 않는다.
- **결정:** 안정적인 디렉터 기준과 계속 변하는 디렉터 상태를 서로 다른 기록 면으로 둔다. 기준은 기존 제품 정본을 우선 재사용하고 적합한 정본이 없을 때만 `docs/director-charter.md`를 만든다.
- **이유:** 현재 상태와 장기 기준의 갱신 주기를 분리하면서 `AGENTS.md`나 스킬 일반 규칙을 중복하지 않기 위해서다.
- **영향:** 기본 상태 문서는 계속 작게 유지하며, 저장소 전체가 항상 읽는 지침에는 필요할 때 두 기록 면으로 가는 짧은 경로만 둘 수 있다.
