# 제품 수렴 중심 디렉터 개선

## Goal

- 디렉터가 큰 제품 결과를 충분히 해석하고, 충분히 큰 전문 책임만 위임하며, 국소 문제에 끌려가지 않고 실제 완료까지 수렴하도록 실행 계약을 보강한다.

## Scope

- 정본 스킬의 한영 계약과 설계 방향을 최소 범위로 맞춘다.
- 감시 역할이나 고정 장부를 추가하지 않고 제품 방향, 분업 크기, 의견 분류와 간접 구현 인수 경계를 다룬다.
- 안정적인 제품·운영 기준과 계속 변하는 현재 상태를 서로 다른 기록 면으로 분리한다.

## Current Facts

- 기존 계약은 사용자 가시 작업자와 디렉터 내부 에이전트를 구분하지만, 작은 문제의 과도한 세션화와 내부 에이전트 연쇄를 통한 간접 구현 인수를 충분히 판정하지 못한다.
- 실제 실패에서는 여러 세션이 국소 경계를 지켰어도 제품 방향을 끝까지 소유하고 결과를 통합하는 책임이 약해 전체 수렴이 멈췄다.

## Current State

- 제품 해석, 세션화 기준, 의견 분류, 간접 구현 인수, 동일 실패와 제품 진척 규칙을 로컬 정본에 반영했다. 기존 정본 또는 `docs/director-charter.md`가 안정적인 기준을, `docs/director-state.md`가 현재 행동과 대기를 맡도록 분리했다. 스킬 형식과 변경분 검사가 통과했고 여덟 개 독립 사전 행동 실험이 기대한 경계를 모두 선택했다.

## Next Step

- 사용자 검토 뒤 승인되면 정본 게시와 Project Legibility 생성 묶음 갱신을 별도 단계로 진행한다.
