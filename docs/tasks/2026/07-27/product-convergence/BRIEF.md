# 제품 수렴 중심 디렉터 개선

## Goal

- 디렉터가 큰 제품 결과를 충분히 해석하고, 충분히 큰 전문 책임만 위임하며, 국소 문제에 끌려가지 않고 실제 완료까지 수렴하도록 실행 계약을 보강한다.

## Scope

- 출시된 제품 수렴 규칙을 유지하고, 후속으로 디렉터의 능동적인 하위 작업 관리 경계를 검토한다.
- 고정 주기 감시나 과도한 상태 조회를 기본값으로 만들지 않고 완료 보고 누락, 수동 대기와 조율 공백을 다룬다.
- 내일 검토 전에는 스킬 계약이나 출시본을 더 변경하지 않는다.

## Current Facts

- 제품 해석, 충분히 큰 책임만의 분업, 국소 문제 유지와 간접 구현 인수 금지는 정본과 Project Legibility 0.6.3에 출시됐다.
- 하위 작업이 완료 사실을 디렉터에게 돌려주지 않거나, 디렉터가 보고를 기다리며 다음 계획·조율·위험 관리 없이 수동 대기하는 사례가 남아 있다.
- 지나치게 잦은 확인은 작업자의 집중을 방해하고 디렉터의 토큰을 낭비할 수 있으므로, 능동성 자체보다 사건 기반 확인과 관리 예산의 경계를 함께 설계해야 한다.

## Current State

- 0.6.3 출시는 완료됐다. 능동적인 하위 작업 관리 문제는 후속 검토 대상으로만 기록했으며 해법 선택, 스킬 수정과 새 실험은 시작하지 않았다.

## Next Step

- 내일 완료 보고 계약, 사건 기반 확인 시점, 대기 중 디렉터가 계속 소유할 계획·조율 업무, 확인 빈도와 토큰 예산을 함께 검토해 최소 규칙 후보를 정한다.
