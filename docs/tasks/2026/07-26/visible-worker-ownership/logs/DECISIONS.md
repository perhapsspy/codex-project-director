- **배경:** 작업자라는 표현이 사용자 가시 작업 세션과 디렉터 내부 에이전트를 구분하지 않아 디렉터가 내부 실행을 연속 지휘할 수 있었다.

- **영향:** 다른 작업 세션은 자기 담당 경계 안에서 보조 에이전트를 계속 사용할 수 있으며, 프로젝트 계약과 변경 담당 경계는 디렉터가 관리한다.
