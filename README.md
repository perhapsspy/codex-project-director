# Codex Project Director

[한국어](README.md) | [English](README.en.md)

## 요약

여러 Codex 작업이나 세션을 하나의 검증된 프로젝트 결과까지 이끄는 director 스킬입니다. 디렉터는 목표, 우선순위, 작업 간 계약, 증거와 복구를 조정하고 구현은 작업자에게 맡깁니다.

이 저장소가 독립 정본이며 Project Legibility에는 아직 편입하지 않았습니다.

## 빠른 시작

`skill-installer`로 이 저장소의 `skills/codex-project-director`를 설치합니다.

```text
$skill-installer로 perhapsspy/codex-project-director 저장소의 skills/codex-project-director를 설치해줘.
```

그다음 새 세션을 director session으로 명시 지정합니다.

```text
이 세션을 디렉터 세션으로 운영해. 하나의 Codex Goal을 시작하고 이 여러 작업을 검증된 통합 완료까지 지휘해줘.
```

`$codex-project-director`로 직접 호출할 수도 있습니다.

## 이런 때 사용

- 여러 작업이나 세션이 하나의 프로젝트 결과와 완료 기준을 공유할 때
- 진행 상황, 작업 간 계약, 의존성과 blocker를 능동적으로 조정해야 할 때
- 여러 완료 주장을 증거로 통합하고 프로젝트 완료를 판단해야 할 때

하나의 국소 구현, 디버깅, 리뷰나 상태 요약에는 사용하지 않습니다. 사용자가 현재 세션을 디렉터나 감독으로 명시 지정할 때 적용되며, `$codex-project-director`로 직접 호출할 수도 있습니다.
