# Codex Project Director

여러 Codex 작업을 하나의 검증된 프로젝트 결과까지 이끄는 디렉터 스킬입니다.

디렉터는 직접 product code를 구현하지 않습니다. 목표, 우선순위, 작업 간 계약, 증거, 복구와 handoff를 소유하고 작업자와 리뷰어가 서로 다른 입장을 유지하도록 조정합니다.

현재는 실제 디렉터 세션을 바탕으로 운영 계약을 다듬는 독립 실험 단계입니다. 안정화된 뒤 Project Legibility의 선택형 운영 보조로 포함할지 판단합니다.

## 현재 초점

- active non-implementing director
- 상태 전이 기반 감독
- 작업자를 돕거나 보조·대체 작업자를 배정하는 복구
- 증거 기반 승인과 교차 작업 계약 조정
- polling, 중복 검증과 역할 붕괴로 인한 토큰 낭비 방지
