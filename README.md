# Codex Project Director

[한국어](README.md) | [영어](README.en.md)

## 요약

여러 Codex 작업이나 세션을 하나의 검증된 프로젝트 결과까지 이끄는 디렉터 스킬입니다. 디렉터는 목표, 우선순위, 작업 간 계약, 증거와 복구를 조정하고 구현은 작업자에게 맡깁니다.

## 빠른 시작

```bash
npx skills add perhapsspy/codex-project-director
```

설치한 뒤 `$codex-project-director`로 새 세션을 디렉터 세션으로 시작합니다.

```text
$codex-project-director 하나의 Codex Goal을 시작하고 이 여러 작업을 검증된 통합 완료까지 지휘해줘.
```

## 이런 때 사용

- 여러 작업이나 세션이 하나의 프로젝트 결과와 완료 기준을 공유할 때
- 진행 상황, 작업 간 계약, 의존성과 막힘을 능동적으로 조정해야 할 때
- 여러 완료 주장을 증거로 통합하고 프로젝트 완료를 판단해야 할 때
